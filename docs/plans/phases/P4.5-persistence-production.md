- **P4 完善（Task 4）**：持久化基线上 P4 回归全绿 + 「合并→重启→数据仍在」贯通测试 + 双写一致性修复。

- **多模态（Task 7）**：OCR（PaddleOCR-VL）/ 识图（qwen3-vl）接口 + `ImageLoader` + `/query/with-image` 带图问答。

## 依赖与风险（已全部化解/记录）

- **不可逆清 SQLite**：旧 `data/*.db` 作废；本地强依赖 `.env` 真库。缓解：单独 PR + CI `-m "not db"`。
- **pgvector 维度对齐**：维度进 config，建表前断言。
- **Neo4j+PG 双写非原子**：Task 4 策略 v1（PG 先写、Neo4j 权威后写 + 可重试收敛）；跨 store 原子性留 P9。
- **增量 delete 误删**：`prune_source_chunks` 空集才删；测试「共享实体保留」。
- **异步 worker 丢 job**：启动扫 running->failed；Celery+Redis 留 P9。
- **三段式阈值经验值**：阈值进 config 可调；真实模型评估留待后续。
