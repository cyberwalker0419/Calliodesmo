## 风险与对策

- litellm >= 1.93 在 Windows 无预编译 wheel（需 Rust/MSVC 工具链），已钉 `>=1.85,<1.91` 纯 Python wheel 区间；升级时重新评估。
- BGE-M3（FlagEmbedding + torch）为重依赖，列为可选 extra；P1 真跑嵌入前执行 `uv sync --extra embedding-local`。
- Neo4j 社区版单机即可；P1 前无需集群。
